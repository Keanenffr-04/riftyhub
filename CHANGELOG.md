# Changelog

## v1.0.0 – Foundation and core dashboard
- Vite + React 18 + TypeScript project setup
- Dark design system (CSS variables, no CSS framework)
- Sidebar navigation (mobile drawer), top-bar search
- GitHub username search with validation
- GitHub REST API integration: profile + public repositories (up to 300, paginated)
- Overview page: profile card, profile stats, recently active repositories
- Repositories page: card and table views
- Loading skeletons; error states for not found, rate limit, network failure
- Netlify config (`netlify.toml`) for SPA routing
